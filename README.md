# 🔗 Agregador de Links Pessoal

Este é um projeto simples e objetivo desenvolvido para centralizar minhas redes sociais, portfólio e meios de contato em um único lugar. A página foi construída do zero e está hospedada publicamente utilizando o **GitHub Pages**.

---

### Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página e dos botões.
* **CSS3:** Estilização moderna com tema escuro (Dark Mode) baseado na identidade visual do GitHub.
* **Font Awesome:** Ícones vetoriais integrados para identificação visual das plataformas.
